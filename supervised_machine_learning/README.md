Performs K-fold cross-validation of random forest, linear regression (Lasso and Ridge), SVM, and neural network models that are trained to classify cancer patients from the healthy individuals. The classifiers are trained using expression of neoepitopes, circular RNAs, and transposable elements as biomarkers. The features/biomarkers were selected using wilcoxon test and 2-fold expression. For complete description of methods, check section 2.8 to 2.11 of the publication : https://academic.oup.com/bioinformatics/article/41/5/btaf138/8124074

The script runs N iterations for the given data and produces files with F1, balanced accuracy, specificity, sensitivity, and AUROC scores for each fold, including the averaged scores per iteration. In addition, it plots the overlpped ROC curves from K folds in each of the N iterations and the expected sensitivity per specificity, which is calcullated by fitting a generalized additive model. Check Figure 6 here: https://academic.oup.com/bioinformatics/article/41/5/btaf138/8124074#518357705
