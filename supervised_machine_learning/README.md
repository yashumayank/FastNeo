Fully automated script to run N iterations of K-fold cross-validation of random forest, linear regression (Lasso and Ridge), SVM, and neural networks for classifying cancer patients. The classifiers are trained using expression of neoepitopes, circular RNAs, and transposable elements as biomarkers. The feature selected using wilcoxon test and 2-fold expression. For complete description of methods, check section 2.8 to 2.11 of the publication : https://academic.oup.com/bioinformatics/article/41/5/btaf138/8124074

As a result, this script produces files with F1, balanced accuracy, specificity, sensitivity, and AUROC scores for each fold, including the averaged scores per iteration. In addition, it plots the overlpped ROC curves from all the K folds in N iterations and the expected sensitivity per specificity, which is calcullated by fitting a generalized additive model. Check Figure 6 here: https://academic.oup.com/bioinformatics/article/41/5/btaf138/8124074#518357705
