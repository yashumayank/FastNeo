Fully automated script to run N iterations of K-fold cross-validation of random forest, linear regression (Lasso and Ridge), SVM, and neural networks for classifying cancer patients. The classifiers are trained using expression of neoepitopes, circular RNAs, and transposable elements as biomarkers. For complete description of methods, check section 2.8 to 2.11 of the publication : https://academic.oup.com/bioinformatics/article/41/5/btaf138/8124074

As a result it produces tab-seperated files with F1, balanced accuracy, specificity, sensitivity, and AUROC scores for each fold, including averaged values per iteration. It also plots an overlpped ROC curve for all the K folds in N iterations. Check Figure 6 here: https://academic.oup.com/bioinformatics/article/41/5/btaf138/8124074#518357705
